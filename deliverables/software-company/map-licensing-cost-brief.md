## 0. 一句话结论

- **申请 Key 本身 0 元** —— 实名认证即可，不花钱。
- **真正的钱在「技术服务许可」：高德基础版 ¥50,000/年，高级版 ¥100,000/年。**
- **触发条件不是调用量，而是「是否以商业目的使用」。** 免费额度被严格限定为「非商业目的」，且只保 1 年。
- 急救侠当前（未收费、未投标、试点期）落在免费档 → **现在 0 元**；一旦 B2B 培训收费或参与政府采购投标 → **年费 5 万起**。

## 1. 两笔账必须分开算

| 项目 | 金额 | 说明 |
|---|---|---|
| 申请 Key | **¥0** | 高德/腾讯/天地图均免费。只需账号 + 实名认证（个人身份证 / 企业营业执照） |
| 技术服务许可（商用授权） | **¥50,000/年** 起 | 高德基础版；这是唯一的刚性大额支出 |
| 超额流量 | **≈¥0** | F1 只用「JS 地图图面初始化」，3 元/万次 = 0.0003 元/次 |
| QPS 包（提并发） | 不需要 | 400~1500 元/月/10QPS，急救侠并发远未触及基础配额 |

**关键认知：授权费是「准入费」，与调用量无关。** 调用 1 次和 100 万次，只要被判定为商业目的，这笔钱就得付。

## 2. 红线判定：什么叫「商业目的」

高德服务协议明确列举（不是模糊表述）：

- 向第三方或公众用户收费
- **参与项目投标**
- 用于内部管理系统或后台管理系统
- 委托开发
- 其他直接或间接获取收益的用途

对急救侠的直接映射：

| 事实 | 判定 |
|---|---|
| 建议书中「企业安全培训 B2B 服务」 | **直接收益 → 构成商业目的** |
| 「核心急救功能对公众永久免费」 | ⚠️ **不等于非商业目的**。只要其他业务线收费，整体使用可能被判定为商业使用 |
| 参与政府项目投标 | **明确列入商业目的清单** |
| 纯公益、零收入、不投标 | 可争取「非商业目的」认定 → 免费 |

> ⚠️ 「我们主功能免费」是最常见的误判。判定看的是**使用者是否以商业目的使用**，而不是某一个功能模块是否收费。

## 3. 免费档的真实边界（最容易踩的四个坑）

1. **免费月配额不是永久的。** 官方原文：非商业目的的开发者「享有的 **1 年** 的免费月配额量（自注册认证之日起计算）」。第 13 个月开始，即便仍属非商业，也可能需要重新评估或付费。这对「永久公益」定位是个隐性炸弹。
2. **配额跨端共享。** 基础 LBS 服务的月配额在 API / JS / Android / iOS / 微信小程序之间**共享同一份**，不是各端独立。
3. **超额不静默扣费，但会停服。** 超限后返回 `QUOTA_EXCEEDED`，服务降级停用；只有完成企业认证 + 绑定账户 + **手动开启**自动续费后才会自动扣费。生产环境必须配置用量告警（支持 90% 阈值提醒）。
4. **企业认证 ≠ 非商业。** 完成企业认证只是解锁配额通道，不改变「是否商业目的」的判定。

**免费月配额量级（高德，实用参考）**

| 服务 | 个人非商业 | 企业非商业 | 企业（已购许可） |
|---|---|---|---|
| 基础地图定位（含 JS 地图图面初始化） | 150 万次/月 | **3,000 万次/月** | 9,000 万次/月 |
| 基础 LBS（路径规划/地理编码等） | 15 万次/月 | 300 万次/月 | 900 万次/月 |
| 基础搜索 | 5,000 次/月 | 5 万次/月 | 50 万次/月 |

→ 急救侠 F1 落在第一行。即便按 3,000 万次/月的**非商业**档位，也远远用不完。

## 4. 急救侠的真实用量成本

F1 范围 = 「JS 地图图面初始化 + 自有 AED 点位展示」，**不涉及**路径规划、逆地理编码、POI 搜索。

| 场景 | 月调用 | 超额成本 |
|---|---|---|
| 轻度（日活 1 千，人均开图 1 次） | 3 万次 | 约 **¥9/月** |
| 重度（日活 1 万，人均开图 3 次） | 90 万次 | 约 **¥270/月**（3 万次以内基础定价，超出走 8 折阶梯） |
| 极端（千万级/月） | 1,000 万次 | 约 ¥1,800/月，且应联系商务 |

**结论：超额流量费对急救侠可以忽略，刚性成本只有授权年费那一笔。** 预算讨论不必纠缠流量单价。

## 6. 四条可选路径（成本从低到高）

### 路径 A：¥0 —— 先跑起来，边跑边合规

**前提**：商业模式不变，仍属非商业目的。用企业认证 + 免费月配额。
**风险**：① 免费配额只有 1 年；② 一旦收费即违约，需补缴。
**适合**：开发联调、试运行、Demo、政府试点期。

### 路径 D：¥0 + 政府背书 —— 天地图（**最值得先问的一条**）

《地理信息公共服务指南（试行）》明确：**地方政府主导的公益性智慧城市、数字孪生建设项目，可免费提供统一时空地理信息底座授权**；公共文化领域也可免费授权用于公共文化产品开发。

与急救侠「政府合作 + 社会公益」的定位高度契合。而且 AED 点位是自有数据（自绘点即可），底图够用 —— 天地图 POI/实时路况弱这一短板在 F1 场景**不构成障碍**。

**需要核实两点**：① 急救侠是否满足「政府主导的公益性项目」；② 应用分发形态是否触发商用审核（APK/IPA 硬编码 Key 属风险行为，H5 相对安全）。
**行动**：先发工单问，这是成本最低的一条路，也是唯一可能把底图成本压到 0 的路。

### 路径 B：¥20,000/年 —— 丰图项目版（性价比档）

⚠️ 项目版是「**纯证书不含接口额度**」，需确认是否还要单独买流量包 → **实际 TCO 可能高于 2 万**。必须先找商务确认打包口径，不要按 2 万做预算。

### 路径 C：¥50,000/年 —— 高德基础版 / 腾讯基础版（推荐主线）

- **若急救侠以 uni-app + 微信小程序为主入口** → 腾讯更划算：小程序地图原生支持、省包体省调用、基础版限时赠 12 个月，且高级档比高德便宜 3 万。
- **若以 H5 / 独立 App 为主、且重视社区踩坑资料** → 高德（文档成熟度是四家最好）。
- **采购建议：不要现在锁死供应商。** F1 PRD 已要求 SDK 走**薄适配层**封装 → 换供应商只改一个文件。先用免费额度把功能做出来，采购决策往后放。

## 7. 顺带的省钱杠杆

1. **乘风计划**：符合平台认定标准的初创/小微企业可免费获得 **1 年「企业认证开发者-乘风计划」基础服务**。现阶段是**定向邀请机制，不能自助申请** → 必须通过工单/商务主动争取。**这条值得试一次，问一句的成本是零。**
2. **本地缓存**：AED 点位、行政区划等低频数据缓存 + TTL，可减少 30%+ 调用。
3. **不做逆地理编码**：`aed_devices` 表（`急救侠-server/src/db.ts:105-132`）已自带地址字段，**不需要**拿经纬度反查地址。这是一个容易顺手多花钱的地方。
4. **不做点位聚合/静态图**：F1 不需要。

## 8. 与 F1 的依赖关系（硬关联）

F1 AED 真实地图的**唯一外部前置条件就是 Key**。而申请 Key 需要：

- 企业实名认证（营业执照）
- **生产域名 / 包名**用于白名单绑定

  - JS API Key → 需配置 HTTP 引用白名单（域名）
  - 服务端 Key → 需配置 IP 白名单

→ **这与 `aliyun-action-sheet.md` 的 A3（服务器 + 域名）、B4（企业实名）是同一条前置。两件事应合并推进，不要重复排期。**

→ **在 Key 到位前，F1 必须能降级为列表模式**（PRD 已列为硬要求），**不允许白屏**。
