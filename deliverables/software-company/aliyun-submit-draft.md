## 1. 控制台填报（复制块）

### 1.1 短信签名
```
签名来源类型：已注册商标名
签名文字：急救侠
需上传：商标注册证（持有方须 = 本阿里云账号主体）
```
> ⚠️ 商标前提硬 gate：若「急救侠」商标**非账号主体直接持有 / 非全网唯一 / 挂在个体户法人个人名下」
> ⇒ 报备必失败，须回退 D1 为「企事业单位名」。**提交前先确认商标证号 + 持有方（见 §4 待填）。**

### 1.2 短信模板（类型：通知短信；变量逐字一致）
```
模板正文（不含签名）：
${device}（${address}）被取用，请责任人尽快确认授权。

模板类型：通知短信
变量：${device}  ${address}
```
- 字数：正文 36 字 + 签名 `【急救侠】`5 字 = **41 字 ≤70 ✓（1 条计费）**
- 变量预算：`device + address` 合计 ≤48 字不超 70
- 语义：通知类（无营销词），口吻 = 告知设备被取用 + 请责任人确认授权

> 备选 B（点明"您负责的"）：`您负责的${device}（${address}）有急救取用请求，请立即确认授权。`（46 字，变量 ≤43 字）。二选一提交。

### 1.3 语音 TTS 模板（公共模式；变量仅 `device`）
```
TTS 文案：
急救侠提醒：${device}有急救取用请求，请责任人尽快确认授权。

外呼模式：公共模式（SingleCallByTts，不填 CalledShowNumber）
变量：${device}
```
- 字数：34 字（语音无签名）
- 与代码 `smsReportService.ts:185` 变量名 `device` 一致（无 `address`）

## 2. 变量 ↔ 代码逐字对齐（提审后勿改错）

## 3. 提交后动作（来自 aliyun-action-sheet.md 阶段 B/C）

1. 企业实名已通过（A1）→ 提交签名（B1）/ 模板（B2）/ 语音（B3）
2. 开启**短信状态报告 → HTTP 批量推送**，URL 填 `https://<域名>/api/public/aliyun-sms-report`（依赖 E2 已备案/可达域名）
3. 生成 **RAM 子账号** AccessKey（`dysms:SendSms`、`dyvms:SingleCallByTts`），写入**仓库根 `.env`**（生产）
4. 报备期 ≥10 工作日（官方不承诺）；期间签名不可用、不可编辑
5. 通过后通知我跑 `docs/DEPLOY.md §11` 七项验收
