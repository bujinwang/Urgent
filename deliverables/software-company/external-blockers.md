## 2. E2 · 服务器 + 域名 + ICP 备案（新建清单）

> 为什么单列：`docs/DEPLOY.md` 把「域名 A 记录 + 放行 80/443」当部署前提，但**没有 ICP 备案（网站备案）的独立清单**。中国大陆机房 + 域名**必须 ICP 备案**，否则域名无法合规解析 / 会被阻断。且 E1 的短信回调（`https://<域名>/api/public/aliyun-sms-report`）**依赖**本项已备案的公网域名。

### 关键路径（按序，部分可并行）
1. **决策：机房位置**
   - 中国大陆 → **必须 ICP 备案**（1–3 周，管局审核，不承诺）
   - 境外（香港 / 海外）→ 免 ICP 备案，但用户数据含个人信息，需评估数据出境合规
2. **域名**
   - 若主体**已备案** → 新子域名可能只需「新增接入」（较快）；先确认现有备案是否覆盖
   - 若**未备案** → 需先有域名 + 服务器才能发起备案
   - ⚠️ 域名主体须与 E1 阿里云资质主体**一致**（坑：资质固话=ICP 备案电话）
3. **采购服务器**（ECS / 轻量应用服务器）
   - 配置参考 `docs/DEPLOY.md §1` 主机前提：放行 **80/443（TCP）**、建议 **443/UDP**；取公网 IP
   - 起步建议 2C4G（按真实并发再调）；确认地域与第 1 步一致
4. **ICP 备案（管局）**
   - 资料：营业执照、法人证件、网站负责人证件 + 人脸核验、真实性核验单
   - 要求：域名 + 服务器已就位；按接入商指引（部分要求先接入 / 关闭解析）
   - 时长：**1–3 周**（官方不承诺）
5. **（可选 / 视地方法规）公安备案**（联网单位备案）
6. **HTTPS**：Caddy 自动签（DEPLOY.md §2.3 `DOMAIN=你的域名`）
7. **部署**：DEPLOY.md §2

### 依赖 / 坑
- E2 与 E1 抢同一时间线 ⇒ **今天并行启动**。
- 备案主体固话须 = E1 阿里云资质固话（同主体，避免来回改）。
- 备案完成前，域名一般不可对外提供公网服务（影响 E1 回调 URL 验证）。

### 我需要你给的（推进 E2）

- 是否已有备案主体 + 域名（及域名）
